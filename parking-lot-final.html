Problem Statement and Motivation

Problems in manual parking

  • Difficult to identify available slots
  • Manual record maintenance
  • Time-consuming vehicle searching
  • Difficulty tracking parked vehicles
  • Parking fee calculation may need manual work
  • Possibility of incorrect or duplicate entries

Motivation

Our project aims to provide a simple computerized solution that makes parking management faster, organized and easier to maintain.

PERSON 2Park and remove2/4

park(): Duplicate Registration Check

Vehicle v;
cout << "\nRegistration Number: ";
cin >> v.regNo;

for (auto &x : vehicles) {
  if (x.regNo == v.regNo) {
    cout << "Vehicle already parked!\n";
    return;
  }
}

Why check first

The same vehicle cannot occupy two slots, so duplicates are rejected.

Complexity

Linear search over the vector: O(n).

v.row--;  v.col--;

  cout << "Slot already occupied!\n";

Index conversion

Subtract 1 from row and column to get array indices.

Errors handled

Invalid slot and already occupied slot both stop with a message.

  }
}

Linear search

Checks each record in order and stops at the first match: O(n).

Why linear

At most 12 vehicles, so a simple scan is enough.
